# 认识么 KnowMo（安卓版）

> Learn life, one word at a time. —— 学生活，从认一个字开始。

面向识字较少老年人的安卓识字辅助应用。**抖音式垂直滑动学习**：生活词组为学习单元、顶部场景频道切换、新学与复习按记忆曲线混排、全程语音引导。

技术栈：Kotlin + Jetpack Compose（`VerticalPager` 实现 feed），无第三方依赖（仅 AndroidX + Compose），minSdk 26。

## 构建

### 方式一：Android Studio（推荐）

1. 安装 [Android Studio](https://developer.android.com/studio)（Koala 及以上，自带 JDK 17 与 Android SDK）。
2. `File → Open` 选择本目录（`android-app/`）。
3. 首次打开若提示 "Gradle wrapper not found"，点提示条中的修复链接（自动生成 wrapper 并下载 Gradle 8.7），或菜单 `File → Sync Project with Gradle Files`。
4. 等待 Sync 完成 → 连接手机（开启 USB 调试）→ 点 ▶️ Run。

### 方式二：命令行（需本机已有 JDK 17 + Android SDK）

```bash
# 首次需要生成 wrapper（本机装过 gradle 的话）
cd android-app && gradle wrapper --gradle-version 8.7

# Debug APK
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

## 交互契约

1. **上下滑学习**：每屏一张学习卡，snap 吸附；卡片进入视口自动朗读（每卡一次）。
2. **生活词组**：如"地铁站"整体学习，配逐字拼音与生活用途说明；点单字读该单字（v18），点卡片其余位置重听「词 + 用途」。
3. **频道切换**：顶部 Tab 分两组——**固定频道**：推荐 / 收藏（恒显示，不可移除）；**场景分区**：全部来自导入的自定义词库（v23 起零内置——官方词库在仓库 `wordbanks/` 以 CSV 分发：公交地铁 / 医院 / 手机微信 / 家电 / 常用字词，传到手机经设置页导入即用；**首次导入自动显示**，重导同名文件 = 替换更新、不动用户改过的显隐）。点按替换 feed 并语音播报。分区显隐与排序在设置页（固定频道不受影响）。**分区收敛（v17 → v18 → v22 → v23）：13 → 10 → 5 → 4 → 0（内置）**——先合并同构与凑数的（`银行` 并入 `办事`、`药品说明` 并入 `医院`、解散 `紧急求助`），再移除四区一网（v18），v22 删「面馆」转私有导入，v23 内置全部退役、官方词库以 CSV 随仓库分发；`常用词` 固定频道随 daily 分区退役删除（那份词进 `常用字词.csv`），「常用词恒入推荐」特例（CHANNEL_COMMON）保留但恒为空集。**零词库空态**：裸装未导入时推荐频道显示导入引导页，导入后自动刷新进学习流（当日空队列即时作废重建，新词不必等到明天）。
4. **复习混排**：推荐频道中到期复习卡与新学卡**交错**（前 3 张内必有新词，做不完的用户也见得到新词）；**清债日**（到期词 ≥ 20）在用户每日配额基础上最多增加 5 张（默认 10 → 15），以复习为主但**新词配额照给**；复习卡先考回忆 → 「√ 认识 / × 忘了」→ 展开答案与间隔反馈。**连击层**：同一个词当日要累计 3 次「认识」才移出当天队列，且第 3 次认识后才提交跨日间隔；任意一次「忘了」即清零重来，未满 3 次时该词在队列里**打散重现**（与源卡至少隔 2 张）。
5. **防泄题与求助通道（v5）**：复习卡未作答时，点卡片只播「再想一想，想起来了吗？」，不念词、不念提示；「👀 想看答案」按钮展开拼音与提示但**不写任何学习状态**，作答按钮保留，看完仍可作答。**温故流与场景分区是纯浏览卡**（v5 R10）：无 √/×、无求助按钮，点卡片直接念词。
6. **完成度、前向拦截与自动前进（v5，仅每日任务频道）**：完成卡与前向拦截**只在推荐（每日任务）频道生效**——完成卡**只在整个队列真的处理完时才出现**（新词都教读过、复习卡都已作答），没有「滑到底即完成」这回事；战果为当日持久计数，重启不归零（**v16 量纲**：认识 → **去重词数**、忘了 → **次数**；连击满 3 次才移出队列，旧的作答次数口径会把 10 个词报成「认识了 30 次」）。**不允许越过未处理的卡**——向前滑过未作答/未教读的卡会被**静默**退回该卡（不播提示语），列表顺序与任何学习状态都不受影响；**下滑回看（可翻回以前任意一张已处理的卡）、以及完成卡之后的自由刷不受限制**。**作答后自动前进**：√ / × 之后等「词 + 提示 + 反馈」整句念完，自动翻到下一张（若那是最后一张待处理卡，就落在完成卡上）；新词卡与浏览卡不自动前进，由用户自己上滑。本版没有「跳过」这个动作，出口是 √ / ×（可先「👀 想看答案」再作答）。**自主学习 = 纯浏览的池型频道（v5 R10）**：场景分区 + 完成卡之后的温故流都是「运行时抽词、无限追加、不落库」的浏览流——分区没有完成卡、不拦截、不做到期筛选（进区就是该区全部词，含未学词，加权随机）；**位置恢复（v20 会话快照）**：会话内每个频道只洗一次，切走再切回原样续看（推荐频道浏览模式同理，切回落到离开时的浏览页、完成卡保留首位可回看）；App 重启或跨日后首轮进区仍是新一轮随机；浏览**零写入**——未学词看多少遍都不算学会，新词入口唯一化到每日任务，分区「学完」标记也只能靠每日任务推进（v16 起顶栏用文字「学完」取代 🎓 图标）。
7. **设置页与收藏（v6+）**：设置页为**隐藏入口**——「推荐」tab 连点 5 次（间隔 ≤ 2s）唤出，提供每日学习词数量、每天新词数量、分区显隐与排序（推荐 / 收藏是**固定频道**，不参与显隐与排序，故不在该卡出现）；词卡卡头右侧**收藏按钮**（v19 起与左侧模式徽标**同款小胶囊**：星标 + 文字「收藏 / 已收藏」；收藏 = 金星、未收藏 = 灰星），收藏频道（池型）集中浏览星标词；**在收藏频道内取消收藏，该词的卡即时从收藏页移除**（v20；其他频道浏览中取消收藏不动已出卡，下次装载自然不再抽到）。**学习统计（v14）**：设置页首节为只读统计——已学/学完/收藏总览、今日认识（**词数**）/忘了（**次数**）、连续学习天数（streak，作答日旁路记账、独立 prefs key）、f30 观测小字；受众为家属/年轻人，纯展示零写入。**v16 口径与交互**：总览的分母 = **当前可学的词**（开启的分区；v23 起无内置常用词），关掉的分区不计入（它们已学的进度仍保留，编辑时看得见）；用「**学完 N 词**」而非"毕业"，与频道栏 🎓 的**分区**级毕业区分粒度；**分区进度与该区的显隐/排序合并成一张卡**，分「已显示 / 未显示」两段，段内可**长按拖动**排序（也可用 ↑↓ 微调），「完成」常驻页面底部。语速固定 0.85x（适老偏慢），字号跟随系统缩放；仍不提供字体/语速/提醒入口，无独立生词本；拍照识字为后续扩展占位。**我的词库（v22/v22.1/v23）**：设置页「我的词库」卡——导入词库文件（SAF 选文件，JSON 或 CSV）即成一个**普通自定义分区**，**首次导入自动显示**、重导同名文件 = 替换更新（不动用户改过的显隐），与内置分区同等参与推荐聚合与分区毕业判定；**fail-closed 校验**：拼音逐字配对、库 id 不与内置在用分区/固定频道冲突（已退役分区 id 允许复用，作老设备迁移通道）、库内不重词且不与已有词重复、单库 ≤200 条、库数 ≤10，不合格**整库拒绝**并逐条报告；**删除词库保留该词学习进度与收藏**（id 永不复用口径——重导同 id 的 JSON 进度自动恢复）。格式两选一：JSON `{"id","name","icon"?,"terms":[{"id","text","pinyin","tip"}]}`；**CSV（v22.1）**：用 Excel 填三列（词 / 拼音 / 用途）另存 CSV 即可，**文件名即库名**（库 id 由库名派生——⚠️ 导入后别改文件名，改名视为新词库）；拼音列可空 → android ICU（Han-Latin）自动注音，**多音字可能取错音，导入后建议抽查**；编码自动探测（UTF-8 BOM / UTF-8 / GBK，兜住老版 Excel）；词条 id 由词+拼音哈希派生（改用途说明不动 id，改词=新词，增删行不影响其他词）；CSV 与 JSON 导入后统一转 JSON 规范化存储。**官方词库包（v23）**：仓库 `wordbanks/` 附 5 个 CSV（拼音全填，不依赖自动注音），可自行增删修改后重导——修词直接改 CSV 提 PR。

## 适老化硬指标

词组主字 ≥48sp 等效、拼音与说明 ≥22sp；主色与白底对比度 ≥7:1（WCAG AAA）；反馈按钮 92dp 高；字号跟随系统缩放（app 不叠加自有倍率）；全程无多级菜单、无手势依赖；语音+图标双通道引导。
