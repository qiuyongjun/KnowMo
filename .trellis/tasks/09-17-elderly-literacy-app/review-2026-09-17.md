### P1-1 忘了的词重现卡是只读卡，不能再答一次
- `AppRoot.kt:165` `revealed[t.id] = true` 按 termId 标记；`:180` 重现卡复用同一 id 的 `Page.TermPage(t, CardMode.REVIEW)`
- `AppRoot.kt:246` `revealed = p.mode != CardMode.REVIEW || revealed[p.t.id] == true` → 重现卡恒为展开态
- `TermCard.kt:149` `if (isReview && !revealed)` 才渲染「认识/忘了」按钮 → 重现卡无按钮
- 影响：design「忘了的词追加到队尾一次」退化为纯复读，失去"当天再考一次"的意义
- 改法：`revealed` 按队列位次（如 `$channel:$index`）而非 termId 存 key；或重现卡带独立 `revealed=false` 标记，仅共享 `results` 文案

### P1-2 TTS 就绪前的快速连滑仍会连播
- `TTSSpeaker.kt:53-55` `stop()` 只 `tts?.stop()`，不清 `pendingQueue`
- 冷启动未 ready 时 `speak()` 走 `:43-46` 入队（上限 4），debounce 的 `stop()` 完全无效；就绪后 `:33-37` 全量补播
- 影响：v3 要消灭的"闪播杂音"在冷启动阶段仍在
- 改法：`stop()` 里 `pendingQueue.clear()`，或加 generation 计数，补播前比对

### P1-3 5 字以上词组主字 42sp，低于 prd 硬性 ≥48sp
- `TermCard.kt:93-97` `else -> 42.sp`；命中 market-5、transit-3、bank-2 等长词组
- 违反 `prd.md:45`「词组主字号 ≥ 48sp 等效」
- 改法：`else -> 48.sp`（≥6 字再降到 44sp 并允许换行/缩间距）；README:57「42–64sp」口径需同步

### P1-4 「更大字体」开关无入口，prd AC 落空
- `StudyRepository.kt:65` `setFontScale` 全工程零调用方（grep 确认）；`AppRoot.kt:61-62` 注释自认"不再提供设置入口"
- `setSpeechRate`/`setRemindTime`/`addForgot`/`forgotIds` 同样无调用方；`Sheets.kt` 只剩 `CharSheet`
- 违反 `prd.md:45`（提供更大字体开关）与 `prd.md:100`（设置页含字体/语速/提醒时间/记忆曲线说明）
- 改法：二选一并落字到 prd —— ①恢复极简设置弹层（3 个大开关）；②明确改为"跟随系统字号"并删除该 AC

### P1-5 原型未跟随 v3，已不是 app 的基准
- `prototype/index.html:256-296` 仍保留 `kind`/`days` 静态字段；`:301/:346` 仍消费 `REC_QUEUE`；`:402/:413` 仍有"第 x/y 张"进度条；`:650` 欢迎语仍带队列信息
- 而 `prd.md:102` 规定"原型冻结为下一阶段工程实现的基准"
- 改法：同步原型，或在 prd 明确"v3 原型不再更新，仅保留 v2 演示态"

### P1-6 lastSeen 缺失/损坏的词永久消失（静默）
- `StudyRepository.kt:281` `s.optString("lastSeen")` 缺键返回 `""`；`:87-90` `isDue` 中 `fmt.parse("")` 抛异常被 `runCatching` 吞掉返回 false
- 该词既不算到期（`:167` 过滤）也不算未学（`:173` 排除）→ 永不进每日队列，只在自由刷池偶现
- 影响：步骤 6「JSON 字段读写对称」不成立，故障不可见不可自愈
- 改法：`load()` 入仓校验，lastSeen 为空或无法 parse 时跳过该条（视为未学）；`days` 缺失同理显式处理

### P1-7 断点恢复先把落库位置写成 0，并带动画逐页滚回
- `AppRoot.kt:155-161` `LaunchedEffect(pagerState)` 首帧即发射 `currentPage=0` → `saveQueuePosition(channel, 0)` 先把断点抹掉
- `:134-138` 随后 `scrollToPage(target)` 带动画，滚动中逐页触发 `:157` → 每页一次 `persist()`（全量 JSON 重写，含最多 368 条 TermState）
- 反证：`:207` 已用 `restoreTo != null` 保护播报，说明作者知道跳页期间会错位，但漏了落库
- 影响：冷启动后若立刻被回收，断点归零；恢复过程肉眼可见"刷过去"且伴随反复 `tts.stop()` 的断续声
- 改法：加 `restored` 标志门控落库；跳页改用 `rememberPagerState(initialPage=…)` 或 `requestScrollToPage`

### P1-8 频道 chip 触控热区估算 < 64dp
- `Common.kt:55` `padding(horizontal = 20.dp, vertical = 14.dp)` + `21.sp` 文本 → 估算 ≈56dp
- 违反 `prd.md:47`「触控目标 ≥ 64dp 等效」；这是全 app 唯一需反复点按的控件
- 改法：`vertical` 提到 20-24dp，或 `.heightIn(min = 64.dp)`；实机用布局边界实测
